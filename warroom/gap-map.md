## Occupied (avoid — a competitor already owns it)
- **Ghost-story / horror-story generator** — 9+ live (GhostWriter, GhostLore, GhostWhisper…). RED OCEAN. Organizer-suggested → collision magnet.
- **Haunted terminal / trapped-spirit chat** — 5+ live (Haunted Terminal, Phantom AI). Organizer-suggested.
- **Code séance + Día-de-los-Muertos altar multi-tool** — PhantomTerminal (HIGH threat) already shipped it: ~2k-word post, Gemma-2B/Ollama, Render, a table, local mode.
- **Generic offline spooky-system-prompt chatbot** — the default everyone reaches for.

## Whitespace (unoccupied; the rubric rewards it)
- **W1 — Memorial / Día de los Muertos oral-history keeper** — LOW density (2–3 teams). The theme's memorial half is nearly empty; emotional narratability is high.
- **W2 — TabPFN tabular "ghost"** — BLUE OCEAN (~0 seen). A tabular PREDICTION as the beating heart under a spooky frame is a grand-slam (Overall + Render + TabPFN); sponsor field is thinnest.
- **W3 — Functional/developer-tool twist on the spooky frame** — resurrecting *dead code*, *deprecated functions*, *abandoned repos* as the "ghost." Spooky-but-useful; writes up as a gripping dev build-story.
- **W4 — Cover-image + demo-video craft** — PhantomTerminal (the one to beat) has NEITHER; both are proven winner separators. Any entry that nails both out-competes the field leader on pure post anatomy.

## Missing outcomes (jobs nobody serves)
- **MO1 — "Why did my project die?"** — nobody gives a developer a *post-mortem* of an abandoned repo from its own git/commit history. A real, felt dev pain reframed as a séance.
- **MO2 — "Preserve a person's voice/story before it's lost"** — a memorial keeper that captures oral history into a durable, replayable remembrance; emotionally resonant, currently thin.
- **MO3 — "What happened to this deprecated function?"** — dead/removed code haunting a living codebase; nobody voices or narrates the deprecation graveyard.

## Portability gaps
- Works-elsewhere-not-here: the ghost-story chatbot works identically on any stack → NOT ecosystem-load-bearing in a way the open-innovation prompt rewards. Avoid.
- Here-not-elsewhere: a TabPFN tabular post-mortem is only possible BECAUSE an open-weight tabular foundation model does zero-shot table prediction — it cannot be a plain chatbot. This is the deepest open-weight-core fit in the field.
